# OX 0.1.0

The first stable release: the `ox` relay, OX Desktop, the session host and the paired phone app, for macOS (Apple silicon and Intel) and Linux (x86-64 and ARM64).

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/n0rpan/ox/main/install.sh | sh -s -- --desktop
ox desktop .
```

Leave out `--desktop` for the terminal-only relay. You need stock Codex 0.171.0 or later and/or Claude Code 2.1.331 or later. See the [README](../../README.md) for the first run and phone pairing.

## What is in it

- **Relay and CLI.** Stock Codex and Claude Code on any model API, one setup for both, subscription and API routes side by side, Brave web search, `ox doctor`.
- **OX Desktop.** Native workbench for Codex and Claude Code sessions across projects and billing routes.
- **Session host.** Sessions, approvals and workers keep running when the window closes. `ox host install` starts it at login with launchd or systemd.
- **Phone.** Private web app over Tailscale Serve: pairing by QR, live sessions, approvals and questions, Web Push notifications, per-device terminal access. Funnel is refused.
- **Workers.** Host-owned Codex and Claude Code sessions started by a parent session or by you, nested under their parent.
- **Handoffs.** Continue a conversation in another runtime, route or model with the real recent messages carried over and `read_ox_thread` for the rest.
- **One mode model.** Read, write, classifier and YOLO levels across both runtimes. Children start at their source's level or lower; YOLO children need your acceptance or a stored grant.

## New since the dev builds

- `ox host restart` and the installer upgrade a running host without cutting turns short: the old host stops taking new turns, lets running turns finish (up to 10 minutes), then hands over. Restart retirements say why.
- `ox host doctor` checks the host, Tailscale Serve and Funnel, paired devices, stock client versions against their floors, routes in use and recent host errors, and exits non-zero on a blocking problem.
- `ox host stop`, and `ox host uninstall --purge` to delete OX host state. Codex and Claude Code data is never touched.
- Client and host name the side to update when their protocol versions differ.
- The remote service refuses requests Tailscale marks as Funnel traffic.
- The rmcp `HTTP 404` lines in Codex logs came from test fixtures, not from OX; the fixtures now serve the endpoint, and the gateway's MCP status codes are pinned by a test.

## Upgrade notes

- From a dev build: rerun the install command. A host from before this release cannot drain, so the installer stops it and any running turn is reported as interrupted. Let turns finish first.
- Sessions, pairings and settings are kept.

## Known limits

- Sleep, reboot, network loss and Tailscale loss mid-turn are checked by hand ([release checklist](../design/desktop/release-checklist.md)); host crash and upgrade are automated.
- No Windows host.
