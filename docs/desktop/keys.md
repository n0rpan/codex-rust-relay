# Desktop keyboard shortcuts

Use these shortcuts in the active OX Desktop window. Request shortcuts act on the response shown in the request panel.

| Linux | macOS | Action |
| --- | --- | --- |
| Ctrl+K | Cmd+K | Open or close the command palette |
| Ctrl+N | Cmd+N | Start a new thread on the current project and billing route |
| Ctrl+Alt+↓ | Cmd+Alt+↓ | Select the next thread in the project list |
| Ctrl+Alt+↑ | Cmd+Alt+↑ | Select the previous thread in the project list |
| Ctrl+F | Cmd+F | Find text in the current transcript |
| Ctrl+L | Cmd+L | Focus the current composer |
| Ctrl+Shift+X | Cmd+Shift+X | Stop the active turn or selected running worker |
| Ctrl+B | Cmd+B | Show or hide the project sidebar |
| Ctrl+Shift+D | Cmd+Shift+D | Show or hide the current thread’s changes and plan |
| Ctrl+, | Cmd+, | Open or close Settings |
| Ctrl+Alt+1 | Cmd+Alt+1 | Choose the first response shown for the visible request |
| Ctrl+Alt+2 | Cmd+Alt+2 | Choose the second response shown for the visible request |
| Ctrl+Alt+3 | Cmd+Alt+3 | Choose the third response shown for the visible request |
| Ctrl+Alt+4 | Cmd+Alt+4 | Choose the fourth response shown for the visible request |
| Ctrl+Alt+Enter | Cmd+Alt+Enter | Submit the filled answers for the visible questionnaire |

In the command palette, use ↑ and ↓ to select a result, Enter to open it, and Esc to return to your previous focus.

In the composer, type `@` and a filename, use ↑ and ↓ to select a match, and Tab to insert it. Paste images with Ctrl+V or Cmd+V. Enter sends the draft. Shift+Enter inserts a new line. Ctrl+Enter or Cmd+Enter also sends. In Settings → Appearance & input, choose Ctrl / Cmd + Enter if you prefer plain Enter to insert a new line.
